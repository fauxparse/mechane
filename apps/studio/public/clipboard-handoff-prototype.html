Portable clipboard handoff prototype

Throwaway experiment. Can graph and typed/plain Source value JSON survive native and async browser clipboard handoffs while cold preparation, cancellation and failures leave an existing clipboard untouched?

No Show/API access, codecs, asset adoption, Cut authority or live writes. Envelope member layouts below are illustrative, not the final strict schema. Open through HTTPS for async APIs. Running this fixture changes the system clipboard; it never reads or restores your prior clipboard automatically.
