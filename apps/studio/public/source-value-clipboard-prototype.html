Source value clipboard interactions

Throwaway interaction-state prototype for #876. Can you tell which value gets replaced, where shortcuts go, and what a live write affects?

Simulated Show, Run, permissions and commits. No Show API, persistence or live-data editor. Clipboard buttons use real browser APIs on HTTPS; walkthrough fixtures do not touch the OS clipboard. Typed wire layout is illustrative, pending #877.
