# Flow

## Navigation

A Flow with three Scenes: Red, Green, and Blue. The Flow's default Scene is Red. Each Scene uses its matching color and has buttons that navigate to the other two Scenes.

The Flow is wired to one per-connection Audience Device. Every connection starts at Red and navigates independently from its own browser-local Run state.

# Scenes

## Red

A dark red Scene with buttons for Green and Blue.

## Green

A dark green Scene with buttons for Red and Blue.

## Blue

A dark blue Scene with buttons for Red and Green.
